## 📂 Мои основные проекты

### 🤖 AUH (Roblox RP Automation)
*Система автоматизации ролевых отыгровок для Roblox (изначально для АРРП, теперь под любые RP-плейсы).*

| Аспект | Детали |
|--------|--------|
| **Статус** | Скелет готов, активная разработка неавтоматического режима |
| **Неавтоматический режим** | Python-меню (стиль SAMP-Funcs) с BIO персонажа, режимами (проверка, рейд и др.), ИИ через API (Ollama / Grok). Планируются: звуковые уведомления (NFSMW-стайл), авто-заполнение документов по форматам |
| **Автоматический режим (в планах)** | ИИ сам пишет в чат за игрока, имитируя его стиль. Отключение по биндам |
| **Технологии** | Python (ядро и меню), HTML/CSS/JS (веб-интерфейс для настроек), API Ollama |
| **Инструменты** | VS Code, Git, PyInstaller (сборка в .exe), браузер для отладки веб-части |
| **Ресурсы / БД** | JSON-конфиги (`auh_config.json`, `auh_settings.json`), локальные файлы сценариев |
| **Структура проекта** | `main.py`, веб-папка (`app.js`, `index.html`, `style.css`), сборка через `build.bat`, готовый `AUH.exe` в `dist/` |
| **Особенности** | Два режима работы, интеграция с локальной ИИ-моделью, модульность |

### 🔌 SWILL HUB (Multi-Project)
*Мега-мульти-чит для множества игр — универсальный инструмент с инжектором, спуфером и Lua-скриптами.*

| Аспект | Детали |
|--------|--------|
| **Статус** | Активная разработка, исходники открыты |
| **Инжектор** | Собственная сборка на основе RMMInject / AxionRMMInjectFork. Использует **kernel-level** драйверы, manual mapping, обход Hyperion + Byfron через AMDXX64.DLL |
| **Спуфер** | Открытый HWID-спуфер (встраивается в инжектор) |
| **ИИ-компонент** | При запуске инжектор автоматически проверяет актуальные оффсеты для игр и подгружает их, чтобы скрипты работали без ручного обновления |
| **Визуал** | Интерфейс в стиле Xeno (собственное меню) |
| **Технологии** | C++ (ядро инжектора), ассемблерные вставки, Windows API, драйверное программирование |
| **Инструменты** | Visual Studio 2022, x64dbg, Cheat Engine, Process Hacker, Git |
| **Ресурсы / БД** | База оффсетов (локальный JSON), сигнатуры для обновлений, шаблоны спуферов |
| **Особенности** | Полный обход Hyperion, автоматическое обновление оффсетов через ИИ, поддержка Lua-скриптов, встроенный спуфер |
